# Network Panel X API

This service owns user accounts and aggregated traffic rankings. The Android app must never connect to TiDB directly or contain a TiDB password.

## Setup

1. Copy `.env.example` to `.env` and fill in the rotated TiDB credentials and JWT secret.
2. Set `DATABASE_CA_PATH` to the downloaded TiDB CA certificate, for example `E:\\isrgrootx1.pem` on Windows.
3. Install dependencies and apply the schema:

```bash
npm install
npm run migrate
npm start
```

The migration creates:

- `users`: unique normalized usernames and bcrypt password hashes.
- `traffic_daily`: one absolute daily traffic row per user, including year, month, and day fields for ranking queries.

## API

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/v1/auth/register` | Register a username and password. |
| `POST` | `/v1/auth/login` | Verify credentials and issue a 30-day bearer token. |
| `POST` | `/v1/traffic/sync` | Upload the user's current absolute daily traffic total. |
| `GET` | `/v1/stats/me?period=day|month|year` | Read personal statistics. |
| `GET` | `/v1/leaderboard?period=day|month|year` | Read the top 100 users. |

WebDAV/S3 backup credentials and backup files remain user-owned and are not sent to this API.

## Deploy

The API must run on a public HTTPS host before a physical Android device can use accounts and rankings. The repository includes a production `Dockerfile` and `../render.yaml` for Render.

1. Push this repository to GitHub, then create a Render Blueprint from the repository.
2. Enter `DB_HOST`, `DB_USERNAME`, `DB_PASSWORD`, and `DB_DATABASE` in Render's secret environment variables. Do not create `DATABASE_CA_PATH` there: Node's trusted root store validates TiDB Cloud's Let's Encrypt certificate.
3. Deploy the service, then open `https://<your-service>/health`. It must return `{ "ok": true }`.
4. The container automatically applies the idempotent migration before starting the API.
5. In the Android app's account settings, set the API address to the public `https://` URL.

`JWT_SECRET` is generated by `render.yaml`. For other platforms, set it to a separate random value of at least 32 characters. Never commit `.env`, database passwords, or JWT secrets.
